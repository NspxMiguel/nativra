## Recommendation: Nativra

Nativra echoes native execution without tying the app's name to one storefront
or implying endorsement by a console manufacturer. It is short enough for a TV
library tile and supports a simple N symbol. Suggested Portuguese pronunciation:
na-TEE-vra.

The cover uses a graphite N sculpture, true black, one emerald accent, and the
creator credit. The image is deliberately marked IN DEVELOPMENT; it is visual
identity exploration, not evidence of game compatibility.

- Cover: `nativra-cover-v1.png`
- Exact generation prompt: `nativra-cover-prompt.txt`
- Intended use: draft landscape app cover and promotional key art.
- Review: spelling, creator credit, safe margins, and absence of third-party
  logos were visually checked. Console deployment is validated separately.

## Icon variant

`nativra-icon-v1.png` is the matching square icon. Packaging outputs are resized
from the approved art without changing its proportions; the cover is padded in
black for the wide tile and splash screen.

Icon prompt: Create a square app icon variant from this approved Nativra cover.
Preserve the same graphite sculptural capital N with an emerald diagonal
luminous edge, black background. Center only the N symbol, large and clearly
recognizable at 44 pixels, with generous 15 percent safety margin. Remove all
text, floor reflection and side title from this icon variant. Do not add rounded
corners, no new colors, no other marks. This is the matching installed Xbox app
icon, not a new brand direction.
